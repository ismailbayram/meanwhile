# waitgame Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Claude Code plugin that runs a repository-specific quiz in a second terminal pane while Claude is working, so the developer's context stays loaded for the diff review that follows.

**Architecture:** Three decoupled parts joined by two JSON files on disk. A slash command generates the content pool once and writes `.waitgame/pool.json` (committed). Two shell hooks flip a machine-local state file between `busy` and `idle`. A Python TUI watches that state file and plays cards from the pool. The TUI makes no LLM calls and parses no source code — all code understanding happens at build time, inside Claude.

**Tech Stack:** Python 3.10+, `textual` for the TUI, `pytest` for tests, `hatchling` for packaging, plain bash for hooks, `uvx` for distribution.

**Spec:** `docs/superpowers/specs/2026-08-28-waitgame-design.md`

## Global Constraints

- Python floor: `3.10`. Do not use syntax or stdlib APIs newer than 3.10.
- Runtime dependencies: `textual>=0.80` only. No other runtime dependency may be added. `pytest` is a dev dependency.
- The hooks are **pure bash** — they must not invoke Python, `uvx`, or any network call. They run on every prompt submit and must add no perceptible latency.
- The TUI makes zero LLM calls and zero network calls. If a task seems to need one, the task is wrong.
- Package name on PyPI: `claude-waitgame`. Import package: `waitgame`. Plugin name: `waitgame`. CLI entry point: `waitgame`.
- Committed pool file path, relative to the user's repo root: `.waitgame/pool.json`. Local score file: `.waitgame/scores.json` (gitignored).
- State file path: `~/.waitgame/state/<key>.json` where `<key>` is the first 16 hex characters of the SHA-256 of the resolved project directory path.
- **Agents must not run `git commit`.** The commit steps below give the exact message; stage the files, print the message, and let the repo owner commit.

`src/waitgame/state.py`:

```python
"""Machine-local busy/idle state shared between the Claude Code hooks and the TUI."""

from __future__ import annotations

import hashlib
import json
import os
import time
from pathlib import Path

STATE_ROOT = Path.home() / ".waitgame" / "state"

_VALID = ("busy", "idle")
_IDLE = {"status": "idle", "ts": 0.0}


def project_key(project_dir: str | Path) -> str:
    """Short, stable id for a project directory.

    Must stay byte-for-byte compatible with hooks/waitgame-state.sh:
    sha256 of the resolved path, no trailing newline, first 16 hex chars.
    """
    resolved = str(Path(project_dir).resolve())
    return hashlib.sha256(resolved.encode("utf-8")).hexdigest()[:16]


def state_path(project_dir: str | Path, root: Path = STATE_ROOT) -> Path:
    return Path(root) / f"{project_key(project_dir)}.json"


def write_state(
    project_dir: str | Path,
    status: str,
    root: Path = STATE_ROOT,
    now: float | None = None,
) -> Path:
    if status not in _VALID:
        raise ValueError(f"status must be one of {_VALID}, got {status!r}")
    path = state_path(project_dir, root=root)
    path.parent.mkdir(parents=True, exist_ok=True)
    payload = json.dumps({"status": status, "ts": now if now is not None else time.time()})
    tmp = path.with_name(f"{path.name}.tmp.{os.getpid()}")
    tmp.write_text(payload, encoding="utf-8")
    tmp.replace(path)  # atomic: the TUI polls this file and must never see a half-write
    return path


def read_state(project_dir: str | Path, root: Path = STATE_ROOT) -> dict:
    try:
        data = json.loads(state_path(project_dir, root=root).read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError):
        return dict(_IDLE)
    if not isinstance(data, dict) or data.get("status") not in _VALID:
        return dict(_IDLE)
    return {"status": data["status"], "ts": float(data.get("ts", 0.0))}
```

- [ ] **Step 5: Implement the bash hook**

`hooks/waitgame-state.sh`:

```bash
#!/usr/bin/env bash
# Writes waitgame's busy/idle state file. Invoked by Claude Code hooks.
# Pure bash on purpose: this runs on every prompt submit and must be instant.
set -euo pipefail

# Claude Code sends a JSON payload on stdin. We do not need it, but we must
# drain it so the writing end never blocks on a full pipe.
cat >/dev/null 2>&1 || true

status="${1:-idle}"
dir="${CLAUDE_PROJECT_DIR:-$PWD}"

if command -v sha256sum >/dev/null 2>&1; then
  key="$(printf '%s' "$dir" | sha256sum | cut -c1-16)"
else
  key="$(printf '%s' "$dir" | shasum -a 256 | cut -c1-16)"
fi

state_dir="$HOME/.waitgame/state"
mkdir -p "$state_dir"
tmp="$state_dir/$key.json.tmp.$$"
printf '{"status":"%s","ts":%s}' "$status" "$(date +%s)" > "$tmp"
mv -f "$tmp" "$state_dir/$key.json"
```

Then: `chmod +x hooks/waitgame-state.sh`

Note on `$dir`: Python resolves the path with `Path.resolve()` while bash uses the raw string. If `CLAUDE_PROJECT_DIR` ever arrives with a symlinked or trailing-slash form the keys diverge, which is exactly what Step 2's parity test catches. If it fails, normalize in bash with `dir="$(cd "$dir" && pwd -P)"` and re-run.

`src/waitgame/pool.py`:

```python
"""Reading and validating .waitgame/pool.json.

The pool is produced by an LLM at build time, so every field is treated as
untrusted input: the loader validates shape, not content.
"""

from __future__ import annotations

import json
from dataclasses import dataclass
from pathlib import Path

POOL_RELPATH = ".waitgame/pool.json"


class PoolError(Exception):
    """The pool file is missing, unreadable, or structurally invalid."""


@dataclass(frozen=True)
class QuizItem:
    q: str
    choices: list[str]
    answer: int
    why: str
    source: str


@dataclass(frozen=True)
class MutantItem:
    snippet: str
    lang: str
    clean: bool
    bug: str
    source: str


@dataclass(frozen=True)
class Pool:
    built_at: str
    head_sha: str
    repo: str
    items: list


def _require(raw: dict, key: str, kind: type, where: str):
    value = raw.get(key)
    if not isinstance(value, kind):
        raise PoolError(f"{where}: field {key!r} must be {kind.__name__}, got {value!r}")
    return value


def _quiz(raw: dict, where: str) -> QuizItem:
    choices = _require(raw, "choices", list, where)
    if len(choices) < 2:
        raise PoolError(f"{where}: needs at least 2 choices, got {len(choices)}")
    if not all(isinstance(c, str) and c for c in choices):
        raise PoolError(f"{where}: every entry in choices must be a non-empty string")
    answer = _require(raw, "answer", int, where)
    if not 0 <= answer < len(choices):
        raise PoolError(f"{where}: answer {answer} is out of range for {len(choices)} choices")
    return QuizItem(
        q=_require(raw, "q", str, where),
        choices=choices,
        answer=answer,
        why=_require(raw, "why", str, where),
        source=_require(raw, "source", str, where),
    )


def _mutant(raw: dict, where: str) -> MutantItem:
    clean = _require(raw, "clean", bool, where)
    bug = _require(raw, "bug", str, where)
    if not clean and not bug.strip():
        raise PoolError(f"{where}: a bugged mutant must describe the bug in 'bug'")
    return MutantItem(
        snippet=_require(raw, "snippet", str, where),
        lang=_require(raw, "lang", str, where),
        clean=clean,
        bug=bug,
        source=_require(raw, "source", str, where),
    )


def load_pool(path: str | Path) -> Pool:
    path = Path(path)
    try:
        raw = json.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError as exc:
        raise PoolError(f"pool not found at {path}") from exc
    except (OSError, json.JSONDecodeError) as exc:
        raise PoolError(f"pool at {path} is unreadable: {exc}") from exc

    if not isinstance(raw, dict):
        raise PoolError("pool must be a JSON object")

    raw_items = raw.get("items")
    if not isinstance(raw_items, list) or not raw_items:
        raise PoolError("pool 'items' is empty or not a list")

    items = []
    for index, entry in enumerate(raw_items):
        where = f"item {index}"
        if not isinstance(entry, dict):
            raise PoolError(f"{where}: must be an object")
        kind = entry.get("type")
        if kind == "quiz":
            items.append(_quiz(entry, where))
        elif kind == "mutant":
            items.append(_mutant(entry, where))
        else:
            raise PoolError(f"{where}: unknown type {kind!r}")

    return Pool(
        built_at=str(raw.get("builtAt", "")),
        head_sha=str(raw.get("headSha", "")),
        repo=str(raw.get("repo", "")),
        items=items,
    )
```

```python
"""How far the committed pool has drifted from the working tree."""

from __future__ import annotations

import subprocess
from pathlib import Path

STALE_THRESHOLD = 50


def commits_behind(repo_dir: str | Path, head_sha: str) -> int | None:
    """Commits added since the pool was built, or None if that cannot be known."""
    if not head_sha:
        return None
    try:
        result = subprocess.run(
            ["git", "rev-list", "--count", f"{head_sha}..HEAD"],
            cwd=str(repo_dir),
            capture_output=True,
            text=True,
            timeout=5,
        )
    except (OSError, subprocess.SubprocessError):
        return None
    if result.returncode != 0:
        return None
    try:
        return int(result.stdout.strip())
    except ValueError:
        return None
```

```python
"""Scoring rules. No I/O here — the TUI renders what these functions return."""

from __future__ import annotations

import random
from dataclasses import dataclass, field

from .pool import MutantItem, Pool, QuizItem

CLEAN_EXPLANATION = "Correct as written — no bug in this one."


class GameError(Exception):
    """The caller drove the session into an impossible state."""


@dataclass(frozen=True)
class Verdict:
    correct: bool
    explanation: str


@dataclass
class Session:
    items: list
    index: int = 0
    correct: int = 0
    answered: int = 0
    streak: int = 0
    best_streak: int = 0
    _answered_index: int = field(default=-1, repr=False)


def start_session(pool: Pool, rng: random.Random | None = None) -> Session:
    items = list(pool.items)
    (rng or random.Random()).shuffle(items)
    return Session(items=items)


def finished(session: Session) -> bool:
    return session.index >= len(session.items)


def current(session: Session):
    if finished(session):
        return None
    return session.items[session.index]


def advance(session: Session) -> None:
    session.index += 1


def answer(session: Session, response: int | bool) -> Verdict:
    item = current(session)
    if item is None:
        raise GameError("session is finished")
    if session._answered_index == session.index:
        raise GameError("this item has already been answered; call advance() first")

    if isinstance(item, QuizItem):
        correct = response == item.answer
        explanation = item.why
    elif isinstance(item, MutantItem):
        correct = bool(response) == item.clean
        explanation = CLEAN_EXPLANATION if item.clean else item.bug
    else:  # pragma: no cover - load_pool cannot produce another type
        raise GameError(f"unknown item type {type(item).__name__}")

    session._answered_index = session.index
    session.answered += 1
    if correct:
        session.correct += 1
        session.streak += 1
        session.best_streak = max(session.best_streak, session.streak)
    else:
        session.streak = 0
    return Verdict(correct=correct, explanation=explanation)
```

```python
"""Per-developer running totals. Gitignored: scores are local, never shared."""

from __future__ import annotations

import json
import os
from pathlib import Path

from .game import Session

SCORES_RELPATH = ".waitgame/scores.json"
_ZERO = {"answered": 0, "correct": 0, "best_streak": 0}


def _path(repo_dir: str | Path) -> Path:
    return Path(repo_dir) / SCORES_RELPATH


def load_scores(repo_dir: str | Path) -> dict:
    try:
        data = json.loads(_path(repo_dir).read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError):
        return dict(_ZERO)
    if not isinstance(data, dict):
        return dict(_ZERO)
    out = dict(_ZERO)
    for key in out:
        value = data.get(key, 0)
        out[key] = value if isinstance(value, int) and value >= 0 else 0
    return out


def record_session(repo_dir: str | Path, session: Session) -> dict:
    totals = load_scores(repo_dir)
    totals["answered"] += session.answered
    totals["correct"] += session.correct
    totals["best_streak"] = max(totals["best_streak"], session.best_streak)

    path = _path(repo_dir)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(f"{path.name}.tmp.{os.getpid()}")
    tmp.write_text(json.dumps(totals, indent=2), encoding="utf-8")
    tmp.replace(path)
    return totals
```

```python
"""The terminal UI. Renders cards; all rules live in waitgame.game."""

from __future__ import annotations

from pathlib import Path
from typing import Callable

from textual.app import App, ComposeResult
from textual.containers import Vertical
from textual.widgets import Footer, Static

from . import game, scores
from .pool import MutantItem, Pool, QuizItem


class WaitgameApp(App):
    CSS_PATH = "app.tcss"
    TITLE = "waitgame"

    BINDINGS = [
        ("q", "quit", "Quit"),
        ("space", "next", "Next card"),
        ("c", "clean", "Looks clean"),
        ("b", "bugged", "Has a bug"),
        *[(str(n), f"choose({n})", f"Choice {n}") for n in range(1, 10)],
    ]

    def __init__(
        self,
        pool: Pool,
        repo_dir: Path,
        status_source: Callable[[], str],
        banner: str = "",
        poll_seconds: float = 0.5,
    ) -> None:
        super().__init__()
        self.pool = pool
        self.repo_dir = repo_dir
        self.status_source = status_source
        self.banner = banner
        self.poll_seconds = poll_seconds
        self.session = game.start_session(pool)
        self.frozen = False
        self._answered = False

    def compose(self) -> ComposeResult:
        with Vertical():
            yield Static(self.banner, id="banner")
            yield Static("", id="status")
            yield Static("", id="card")
            yield Static("", id="feedback")
            yield Static("", id="score")
        yield Footer()

    def on_mount(self) -> None:
        self.query_one("#banner").display = bool(self.banner)
        self.set_interval(self.poll_seconds, self._poll_status)
        self._render()

    # --- status ---------------------------------------------------------

    def _poll_status(self) -> None:
        if self.frozen:
            return
        if self.status_source() == "idle":
            self.frozen = True
            self.query_one("#status").update("Claude is done ^ — press q to close")
            if self.repo_dir is not None:
                scores.record_session(self.repo_dir, self.session)

    # --- actions --------------------------------------------------------

    def action_choose(self, number: int) -> None:
        item = game.current(self.session)
        if self.frozen or self._answered or not isinstance(item, QuizItem):
            return
        index = number - 1
        if not 0 <= index < len(item.choices):
            return
        self._resolve(game.answer(self.session, index))

    def action_clean(self) -> None:
        self._mutant_answer(True)

    def action_bugged(self) -> None:
        self._mutant_answer(False)

    def _mutant_answer(self, claim_clean: bool) -> None:
        if self.frozen or self._answered or not isinstance(game.current(self.session), MutantItem):
            return
        self._resolve(game.answer(self.session, claim_clean))

    def action_next(self) -> None:
        if self.frozen or not self._answered:
            return
        game.advance(self.session)
        self._answered = False
        self.query_one("#feedback").update("")
        self._render()

    # --- rendering ------------------------------------------------------

    def _resolve(self, verdict: game.Verdict) -> None:
        self._answered = True
        mark = "correct" if verdict.correct else "wrong"
        self.query_one("#feedback").update(f"{mark} — {verdict.explanation}   [space] next")
        self._render_score()

    def _render(self) -> None:
        item = game.current(self.session)
        card = self.query_one("#card")
        if item is None:
            card.update("Pool exhausted. Run /waitgame-build for a fresh one.")
        elif isinstance(item, QuizItem):
            choices = "\n".join(f"  {n}. {text}" for n, text in enumerate(item.choices, start=1))
            card.update(f"{item.q}\n\n{choices}\n\n({item.source})")
        else:
            card.update(
                f"Is this code correct?  [c] clean   [b] bugged\n\n{item.snippet}\n\n({item.source})"
            )
        self._render_score()

    def _render_score(self) -> None:
        self.query_one("#score").update(
            f"{self.session.correct}/{self.session.answered} correct   "
            f"streak {self.session.streak} (best {self.session.best_streak})"
        )
```

```python
"""Command line entry point: `waitgame` plays, `waitgame validate` checks a pool."""

from __future__ import annotations

import argparse
import subprocess
from pathlib import Path

from . import repo, state
from .pool import POOL_RELPATH, PoolError, load_pool


def repo_root(start: str | Path) -> Path:
    """The git root of `start`, or `start` itself when it is not a repo."""
    try:
        result = subprocess.run(
            ["git", "rev-parse", "--show-toplevel"],
            cwd=str(start),
            capture_output=True,
            text=True,
            timeout=5,
        )
    except (OSError, subprocess.SubprocessError):
        return Path(start)
    if result.returncode != 0:
        return Path(start)
    return Path(result.stdout.strip())


def staleness_banner(repo_dir: str | Path, head_sha: str) -> str:
    behind = repo.commits_behind(repo_dir, head_sha)
    if behind is None or behind < repo.STALE_THRESHOLD:
        return ""
    return f"pool is {behind} commits behind — run /waitgame-build for fresh questions"


def validate(repo_dir: str | Path) -> tuple[int, list[str]]:
    root = Path(repo_dir)
    try:
        pool = load_pool(root / POOL_RELPATH)
    except PoolError as exc:
        return 1, [str(exc)]

    missing = sorted({item.source for item in pool.items if not (root / item.source).exists()})
    if missing:
        return 1, [f"source file does not exist: {path}" for path in missing]
    return 0, [f"pool is valid: {len(pool.items)} item(s)"]


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(prog="waitgame")
    parser.add_argument("command", nargs="?", default="play", choices=["play", "validate"])
    parser.add_argument("--repo", default=".", help="project directory (default: current)")
    args = parser.parse_args(argv)

    root = repo_root(args.repo)

    if args.command == "validate":
        code, messages = validate(root)
        for message in messages:
            print(message)
        return code

    try:
        pool = load_pool(root / POOL_RELPATH)
    except PoolError as exc:
        print(f"{exc}\n\nRun /waitgame-build inside Claude Code to create one.")
        return 1
```

```markdown
---
description: Generate the waitgame question pool for this repository
---

Build `.waitgame/pool.json` for the current repository.

## What to read

Survey the repo to understand what it does and what is distinctive about it:

- data models, schemas, and migrations
- API routes, serializers, and their validation rules
- the README, and any docs describing domain concepts
- `CHANGELOG.md` if present
- `git log --oneline -50` for recent direction

Prefer the project's own domain terms over generic programming vocabulary. A
good question could only be answered by someone who has read this repository.

## What to write

Write `.waitgame/pool.json` with 30-50 items, roughly 60% `quiz` and 40%
`mutant`, using exactly this shape:

    {
      "builtAt": "<today, YYYY-MM-DD>",
      "headSha": "<output of: git rev-parse --short HEAD>",
      "repo": "<repository directory name>",
      "items": [
        {
          "type": "quiz",
          "q": "<question about this project's domain or behavior>",
          "choices": ["<option>", "<option>", "<option>"],
          "answer": <0-based index of the correct choice>,
          "why": "<one sentence explaining the answer>",
          "source": "<repo-relative path the question came from>"
        },
        {
          "type": "mutant",
          "lang": "<language of the snippet>",
          "snippet": "<3-10 real lines from that file, possibly altered>",
          "clean": <true if unaltered, false if you introduced a bug>,
          "bug": "<what is wrong and what it breaks; empty string when clean>",
          "source": "<repo-relative path the snippet came from>"
        }
      ]
    }

Rules for mutants:

- Take real code from the repo, then change at most one thing: an operator
  (`<` to `<=`), a boolean (`and` to `or`), a dropped `not`, an inverted early
  return, a swapped pair of arguments.
- Make about a third of the mutants `clean: true` — unaltered code with an
  empty `bug`. Without those, "looks fine to me" is never the right answer and
  the game teaches the wrong reflex.
- Never invent code. Every snippet must come from a file that exists.
- Wrong quiz choices should be plausible to someone who half-remembers the
  code, not obviously absurd.

## Finish

1. Ensure `.waitgame/scores.json` is in `.gitignore`; add it if missing.
2. Run `uvx claude-waitgame validate --repo .` and fix anything it reports.
3. Tell the user the item count and that `.waitgame/pool.json` is ready to
   commit so their team shares the pool.
```
